# V2.2 验证报告

基线为 V2.1.0。Windows 实机验收使用 DSH 0.2.2-rc.2 的宿主组件和专用测试窗口。

## 第一阶段

- Node 测试 108 项通过。Python 测试 223 项通过，5 项为非 Windows 降级路径，在 Windows 跳过。
- Windows 测试窗通过可见条件等待、窗口批次和前台读回。窗口局部截图保留 400 × 200 原始像素，英文 OCR 定位到唯一目标。复选框勾选与取消勾选均经 UIA 读回，输入后旧帧被拒绝。
- 回归测试覆盖负坐标、混合 DPI 模拟、裁图越界、遮挡、审批撤销、取消通知和批次失败中止。混合 DPI 没有使用第二块实机显示器。

## 第二阶段

- 使用 DSH 原生工具服务验证高级工具仅在加载它的会话内可见。使用原生会话和发布格式校验器验证旧图片引用、文本压缩、原始事件保留和重启回放。
- 两个优化开关默认关闭。启用历史优化只影响后续模型上下文。原始附件和会话事件仍可回看，已经压缩的模型上下文不会因关掉开关而自动展开。

## 基准

每个版本交替运行 8 次冷启动、256 次热调用 `wait(0)`。

| 指标 | V2.1 | V2.2 |
| --- | ---: | ---: |
| MCP 冷启动中位数 | 1,078 ms | 1,061 ms |
| MCP 冷启动 P95 | 1,305 ms | 1,086 ms |
| MCP 热调用中位数 | 1.12 ms | 1.01 ms |
| MCP 热调用 P95 | 1.63 ms | 1.46 ms |
| 精简档工具定义 | 7,157 字符 | 5,637 字符 |
| 标准档工具定义 | 9,216 字符 | 7,574 字符 |
| 全部基础工具和六项可选工具的定义 | 14,153 字符 | 14,027 字符 |

性能值只覆盖本机 MCP 启动和空调用。工具定义以同一方式序列化，字符数不等于 Token。未进行付费模型 A/B 测试。实际 Token、缓存命中和完整桌面任务耗时需按用户的模型路由和任务另行测量。

## V2.2.1 与 DSH 0.2.2-rc.3

- 以 RC3 原生桌面宿主和隔离 Profile 验证。宿主已注册图片历史投影并提供 Token 估算，但该配置没有暴露独立的自动摘要服务。插件改为检查实际使用的接口，保留原设置默认值。
- 在新一轮进入模型请求前，插件替换一张旧截图和一份大结果。原始六份工具结果仍在会话日志，RC3 的持久化格式校验和恢复回放均通过。验收未调用远端模型。
