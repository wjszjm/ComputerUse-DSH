# V2.2 验证报告

基线为 V2.1.0。Windows 实机验收使用 DSH 0.2.2-rc.2 的宿主组件和专用测试窗口。

## 第一阶段

- Node 测试 108 项通过。Python 测试 223 项通过，5 项为非 Windows 降级路径，在 Windows 跳过。
- Windows 测试窗通过可见条件等待、窗口批次和前台读回。窗口局部截图保留 400 × 200 原始像素，英文 OCR 定位到唯一目标。复选框勾选与取消勾选均经 UIA 读回，输入后旧帧被拒绝。
- 回归测试覆盖负坐标、混合 DPI 模拟、裁图越界、遮挡、审批撤销、取消通知和批次失败中止。混合 DPI 没有使用第二块实机显示器。

## 第二阶段

- 使用 DSH 原生工具服务验证高级工具仅在加载它的会话内可见。使用原生会话和发布格式校验器验证旧图片引用、文本压缩、原始事件保留和重启回放。
- 两个优化开关默认关闭。启用历史优化只影响后续模型上下文。原始附件和会话事件仍可回看，已经压缩的模型上下文不会因关掉开关而自动展开。

## 基准

每个版本交替运行 8 次冷启动、256 次热调用 `wait(0)`。

| 指标 | V2.1 | V2.2 |
| --- | ---: | ---: |
| MCP 冷启动中位数 | 1,078 ms | 1,061 ms |
| MCP 冷启动 P95 | 1,305 ms | 1,086 ms |
| MCP 热调用中位数 | 1.12 ms | 1.01 ms |
| MCP 热调用 P95 | 1.63 ms | 1.46 ms |
| 精简档工具定义 | 7,157 字符 | 5,637 字符 |
| 标准档工具定义 | 9,216 字符 | 7,574 字符 |
| 全部基础工具和六项可选工具的定义 | 14,153 字符 | 14,027 字符 |

本节的性能值只覆盖本机 MCP 启动和空调用。工具定义以同一方式序列化，字符数不等于 Token。随后进行的真实模型对照见下文。

## V2.2.1 与 DSH 0.2.2-rc.3

- 以 RC3 原生桌面宿主和隔离 Profile 验证。宿主已注册图片历史投影并提供 Token 估算，但该配置没有暴露独立的自动摘要服务。插件改为检查实际使用的接口，保留原设置默认值。
- 在新一轮进入模型请求前，插件替换一张旧截图和一份大结果。原始六份工具结果仍在会话日志，RC3 的持久化格式校验和恢复回放均通过。这项隔离回放验收未调用远端模型。
- 桌面 Profile 已加载 V2.2.1，标准档注册了 14 项工具。Python 后端版本一致，独立 MCP 握手及五次空调用通过。生产设置页未做界面复验。

### 真实模型对照

通过 RC3 的 DeepSeek Account 适配器调用 `deepseek-flash`，关闭推理，使用同一个自建 Windows 窗口和固定任务。下表是服务端用量，输入总量由未缓存输入、缓存读取和缓存写入相加。表内缓存写入均为 0。

| 测试 | 输入总量 | 未缓存输入 | 缓存读取 | 输出 |
| --- | ---: | ---: | ---: | ---: |
| V2.1 工具定义与整窗图，冷请求 | 5,006 | 5,006 | 0 | 12 |
| V2.2.1 工具定义与局部图，冷请求 | 4,140 | 4,140 | 0 | 12 |
| V2.1 相同请求再发一次 | 5,006 | 142 | 4,864 | 12 |
| V2.2.1 相同请求再发一次 | 4,140 | 172 | 3,968 | 12 |
| V2.2.1 开启按需加载，加载前 | 3,118 | 686 | 2,432 | 12 |
| 带两份旧截图与结果的测试上下文 | 8,258 | 4,674 | 3,584 | 12 |
| 同一测试上下文以短说明代替旧观察 | 4,152 | 568 | 3,584 | 12 |

- 以上七个截图请求的坐标都命中测试控件。另做两次从模型定位到真实点击和 UIA 读回的闭环，两次均成功。输入量为 5,007 → 4,148，模型请求后到完成读回耗时为 1.87 → 2.62 秒。单组闭环出现耗时回退。其他请求的耗时有波动，样本不足以判定端到端性能等效或改善。
- 独立验证了中、英文 OCR 各命中一处，中文字段写入读回一致，窗口条件等待、激活与前台确认均通过。
- 英文和中文各做一次选工具提示对照。英文按要求只返回工具名，中文正确选择了输入工具但直接发出工具调用，测试拦截了调用。输入为 3,745 与 3,742 Token。这组对照无法证明英文天然更省。实际缩减来自工具定义去重和减少图像、历史数据。
- 历史上下文表中是可控的发送载荷对照，宿主插件实际精简与回放另有上文的隔离会话验收。按需加载行只统计加载前，任务需要额外工具时应将加载调用及后续请求计入完整用量。
